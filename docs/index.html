lume

A tiny, agent-friendly, git-like version control system built with machin/MFL. Every command emits JSON. One small native binary.

GitHub → Changelog → Docs →

Install & Try

git clone https://github.com/javimosch/lume.git
cd lume
./build.sh
./lume init
./lume add .
./lume commit -m "first"

JSON-first

Every command prints machine-readable JSON. No interactive prompts. Built for agents and scripts.

Tiny

SHA-256 content-addressed objects, SQLite staging index, and a native binary around 70 KB.

Network aware

Built-in serve, push, pull, and clone commands for self-hosting.

Commands

initcreate a repository
add <path>stage files recursively
statusworking tree status as JSON
commit -m <msg>create commit
loghistory from HEAD
branch [name]list or create branch
checkout <target>switch branch or commit
serverun the object server
push <remote> [ref]upload objects and update ref
pull <remote> [ref]download and fast-forward
clone <remote> [dir]create repo from remote
Built with machin/MFL. Clean-room from the idea of Lit. Source on GitHub.
